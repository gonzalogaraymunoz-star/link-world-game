# LINK WORLD GAME

Interfaz territorial jugable del ecosistema LINK.

## Arquitectura inicial

- Vercel + Next.js: interfaz y runtime
- Google Maps: territorio geográfico real
- LINK WORLD: capa de lectura y juego
- Supabase / Micelio: estado operativo real

## Primer hito

1. Desplegar la interfaz base.
2. Conectar Google Maps.
3. Centrar el territorio inicial en San Pedro de Atacama.
4. Ubicar el primer negocio LINK real.
5. Conectar la ficha del negocio a datos persistentes.
